================================================================================
🔍 POURQUOI CETTE ERREUR ?
================================================================================

La commande `flyctl launch` essaie de DÉTECTER automatiquement le type d'app.
Elle cherche :
   • Un Dockerfile
   • Un fichier de configuration (package.json, requirements.txt, etc.)
   • Un framework connu

PROBLÈME : Parfois, même si le Dockerfile existe, `flyctl launch` ne le voit pas
          ou essaie de le générer automatiquement (et échoue).

SOLUTION : Utiliser `flyctl deploy` qui utilise directement le Dockerfile existant.

================================================================================
📋 COMMANDES COMPLÈTES POUR DÉPLOYER
================================================================================

1️⃣  Aller dans le bon répertoire
   cd /Applications/MAMP/htdocs/strava

2️⃣  Vérifier les fichiers
   ls -la Dockerfile fly.toml app.py

3️⃣  Se connecter à Fly.io (si pas déjà fait)
   flyctl auth login

4️⃣  Configurer les secrets (IMPORTANT - une seule fois)
   flyctl secrets set CLIENT_ID=149497
   flyctl secrets set CLIENT_SECRET=ce7f00ae80b9cfa3ca9cd503b15c73c368a3c97d
   flyctl secrets set REFRESH_TOKEN=1fc5f46d8e959312e0b994af8d2e1f57ac419cf7
   flyctl secrets set INDEX_URL=https://votre-domaine.com/index

5️⃣  Déployer l'application
   
   MÉTHODE A - Avec le script de diagnostic (recommandé) :
   ./diagnostic_flyio.sh
   
   MÉTHODE B - Directement :
   flyctl deploy
   
   MÉTHODE C - Si première fois et que deploy ne marche pas :
   flyctl launch --dockerfile Dockerfile --now

================================================================================
🐛 SI L'ERREUR PERSISTE
================================================================================

1. VÉRIFIER QUE LE DOCKERFILE EST BIEN LÀ
   
   cat Dockerfile
   
   ✅ Doit afficher le contenu du Dockerfile (FROM python:3.11-slim, etc.)


2. VÉRIFIER LES PERMISSIONS
   
   chmod 644 Dockerfile
   ls -la Dockerfile


3. ESSAYER AVEC LE CHEMIN ABSOLU
   
   flyctl deploy --dockerfile /Applications/MAMP/htdocs/strava/Dockerfile


4. SUPPRIMER LE FICHIER fly.toml ET RECOMMENCER
   
   # ATTENTION : Seulement si rien ne marche
   mv fly.toml fly.toml.bak
   flyctl launch --dockerfile Dockerfile --now
   
   # Fly.io va créer un nouveau fly.toml


5. VÉRIFIER LA VERSION DE FLYCTL
   
   flyctl version
   
   # Mettre à jour si nécessaire
   brew upgrade flyctl
