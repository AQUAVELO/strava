⚠️ Problème de connexion avec Strava

Si vous voyez l'erreur "Erreur 403 : limite d'athlètes dépassée", c'est normal — notre application est en phase de développement et Strava autorise un nombre limité de comptes connectés.

Si vous voyez un compte qui n'est pas le vôtre après connexion, cela est dû à une session Strava active dans votre navigateur.

Solution : Utilisez toujours une fenêtre de navigation privée (Cmd+Maj+N sur Mac) pour lier votre compte Strava, après vous être connecté à ScoringFit.
🔑 Comment connecter / déconnecter mon compte Strava

Pour connecter Strava :

  1. Connectez-vous à ScoringFit avec votre email et mot de passe.
  2. Sur votre tableau de bord, cliquez sur le bouton "🔗 Lier Strava".
  3. Vous serez redirigé vers Strava pour autoriser l'accès.
  4. Une fois validé, vos activités apparaîtront automatiquement.
Conseil : Assurez-vous d'être connecté sur Strava.com avec votre propre compte avant de cliquer sur "Lier Strava".

Pour déconnecter Strava :

Rendez-vous sur strava.com/settings/apps et révoquez l'accès à ScoringFit.

♻️ Données Strava non synchronisées

Si vos activités récentes n'apparaissent pas sur votre tableau de bord :

  • Cliquez sur le bouton "🔄 Actualiser" dans votre tableau de bord.
  • Vérifiez que votre activité est bien enregistrée et visible sur strava.com.
  • Les activités privées sur Strava ne sont pas accessibles.
  • Si le problème persiste après 10 minutes, contactez-nous ci-dessous.
🗑️ Comment supprimer mes données / mon compte

Conformément au RGPD, vous avez le droit à la suppression de vos données personnelles.

  • Envoyez-nous une demande via le formulaire ci-dessous en indiquant "Suppression de compte" dans le sujet.
  • Nous supprimerons votre compte et toutes vos données dans un délai de 48 heures.
  • Vos données Strava restent sur les serveurs de Strava — pour les supprimer, rendez-vous sur votre compte Strava.
